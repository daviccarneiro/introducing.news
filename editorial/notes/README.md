# Pontos de revisão das edições

Um arquivo por edição (`<slug da edição>.md`), com uma lista de itens para o mantenedor revisar antes de aprovar: sugestões da curadoria (como a "Minha recomendação"), fatos com fonte única, números sem fonte primária, cortes feitos para caber nos 10 minutos e qualquer dúvida.

O bot do Telegram manda esses itens logo abaixo da prévia da edição (ver "Aprovação no Telegram" no `AGENTS.md`). **Nada disso vai no texto da edição ou do e-mail**: aviso de rascunho, "TODO" ou "[inserir ...]" no conteúdo reprova o `npm test`.

Formato: lista Markdown simples (`- item`), com **negrito**, `código` e [links](https://introducing.news) se precisar.
