Every small company starts with a shared spreadsheet. The problem is not the spreadsheet — it is not knowing when it stopped being enough. These are the signals, and the path I used to move on without building a data team.

## A path in three steps

1. **A single source of truth.** One spreadsheet only, with a fixed schema and column validation. It sounds small; it solves 80% of divergences.
2. **A transformation layer.** dbt running locally, with versioned models. Metrics get a definition instead of a formula hidden in a cell.
3. **Publication.** A simple dashboard reading from the models. If a number changed, there is a commit explaining why.

## What you postpone

Hiring, buying expensive tools and creating a governance committee. None of those steps solve the real problem — which is the problem of definition.
